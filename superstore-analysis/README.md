# 🛒 Superstore Sales Analysis

## Project Overview
Complete exploratory data analysis on a retail superstore 
dataset containing 9,800 orders across 4 regions.

## Key Findings
- **Total Revenue:** $2,261,536 across 9,800 orders
- **Top Category:** Technology ($827,455)
- **Top Region:** West ($710,219)
- **Top Customer:** Sean Miller ($25,000+)
- **Typical Order:** $54 (median) vs $230 (mean)
- **Data Skewness:** 12.98 — highly right skewed
